main.py: точка входу (entry point) застосунку, де ініціалізуються демонстраційні дані та запускається інтерактивне CLI-меню для користувача.

from car_catalog.models import Car 

 

def search_by_brand(cars: list[Car], brand: str) -> list[Car]: 

return [c for c in cars if c.brand.lower() == brand.lower()] 

 

def filter_by_year(cars: list[Car], year: int) -> list[Car]: 

return [c for c in cars if c.year == year] 

 

def find_most_expensive_car(cars: list[Car]) -> Car | None: 

if not cars: 

return None 

return max(cars, key=lambda c: c.price) 

 

def calculate_average_price(cars: list[Car]) -> float: 

if not cars: 

return 0.0 

return sum(c.price for c in cars) / len(cars) 

 

def find_lowest_mileage_car(cars: list[Car]) -> Car | None: 

if not cars: 

return None 

return min(cars, key=lambda c: c.mileage)

Відповіді на контрольні запитання: 

Що таке Python-проєкт? Це структурований набір файлів, каталогів, модулів, залежностей та конфігурацій, об'єднаних для вирішення певного завдання. 

Чим проєкт відрізняється від одного Python script? Скрипт зазвичай складається з одного файла, що швидко стає незручним при збільшенні коду, тоді як проєкт розділений на логічні компоненти з налаштованою системою збірки та тестами.  

Що таке Python module? Це звичайний файл із розширенням .py, який містить код.  

Що таке Python package? Це каталог, що містить файли модулів і спеціальний файл __init__.py.  

Для чого потрібний __init__.py? Щоб вказати інтерпретатору Python, що даний каталог є пакетом, вміст якого можна імпортувати. 

Що таке src-layout? Це структура проєкту, де весь програмний код (модулі, пакети) зберігається у вкладеному каталозі src/.  

Які переваги має src-layout? Це дозволяє чітко розмежувати конфігураційні файли (в корені) від самого коду, запобігає помилкам випадкового імпорту та покращує надійність тестування. 

Для чого використовується virtual environment? Для ізоляції встановлених бібліотек та залежностей проєкту, щоб вони не конфліктували з іншими проєктами або глобальною системою.  

Як створити .venv? За допомогою команди python -m venv .venv.  

Як активувати virtual environment? У Linux/macOS командою source .venv/bin/activate, у Windows — .venv\Scripts\activate.  

Для чого використовується pip? Це стандартний менеджер пакунків Python, який дозволяє встановлювати, оновлювати та видаляти зовнішні бібліотеки. 

Чому рекомендується python -m pip? Це гарантує, що інструмент встановлення pip буде запущено саме з того середовища Python, яке зараз активоване (наприклад, з віртуального). 

Для чого потрібний pyproject.toml? Файл конфігурації, який містить метадані та правила збірки сучасного Python-проєкту.  

Що містить секція [project]? Основні відомості про пакет: назву, версію, короткий опис, мінімальну підтримувану версію Python.  

Що таке editable installation? Режим встановлення через pip install -e ., який дозволяє редагувати сирцевий код проєкту, при цьому зміни автоматично застосовуються без необхідності перевстановлення пакета.  

Для чого використовується if __name__ == "__main__":? Щоб функція (наприклад, main()) викликалась тільки за умови прямого запуску файлу, і не викликалась, якщо файл імпортується як модуль в іншому місці.  

Що таке Git? Розподілена система контролю версій (DVCS) для збереження історії змін, повернення до попередніх станів та роботи в команді.  

Що таке repository? Сховище проєкту під управлінням Git, яке містить усі файли, історію змін та конфігурацію системи контролю версій. 

Що таке commit? Це збережений стан файлів (знімок) у репозиторії на певний момент часу із прикріпленим текстовим описом змін.  

Для чого використовується git status? Для перегляду поточного стану відстежуваних і невідстежуваних файлів та виявлення внесених змін у робочому каталозі.  

Для чого git add? Для додавання змінених файлів до індексу (staging area) з метою підготовки їх до створення коміту.  

Для чого git commit? Для фіксації проіндексованих змін та створення нового запису в історії репозиторію.  

Що показує git log? Хронологічну історію створених комітів у репозиторії.  

Для чого потрібен .gitignore? Щоб перелічити файли або папки (наприклад, кеш, лог-файли), які Git має ігнорувати і не додавати в репозиторій.  

Чому .venv не потрібно комітити? Тому що віртуальне середовище містить дуже багато файлів, залежить від операційної системи розробника і його легко можна відтворити з нуля командою створення.  

Для чого потрібний README? Це головний документаційний файл, який описує суть проєкту та містить інструкції з його налаштування і запуску.  

Що таке type hints? Це механізм анотування типів у Python (наприклад, def main() -> None), який підказує розробнику та редактору коду очікувані типи даних аргументів і результатів виконання функцій. 

Для чого програму розділяють на modules? Це дозволяє логічно структурувати програму: відокремити введення/виведення від моделей даних та бізнес-логіки, що полегшує тестування і підтримку коду.  

Що таке business logic? Це та частина програмного коду, яка виконує основні обчислення, правила обробки та перетворення даних. 

Чому потрібно відокремлювати application entry point від business logic? Це дозволяє імпортувати бізнес-функції для тестування або в інші частини проєкту, не запускаючи при цьому інтерфейс самої програми.
